## Run Locally

### Prerequisites
- Node.js
- npm

### Installation

```bash
git clone https://github.com/Alisabir4/Ali-Sabir-Portfolio.git
cd Ali-Sabir-Portfolio
npm install
npm run dev
```

Open the local URL shown in your terminal to view the website.

### Production Build

```bash
npm run build
```

The production-ready files are generated in the `dist` directory.
