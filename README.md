# Ali Sabir — AI Engineer Portfolio

A responsive portfolio built with React, Vite, Tailwind CSS, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and can be deployed as a static site on GitHub Pages, Netlify, or Vercel. No backend, paid APIs, or secrets are required.

## Personalization

- The supplied portrait is saved at `public/profile.jpg` and is loaded from `/profile.jpg` in development and production.
- Add a verified LinkedIn URL to `LINKEDIN_URL` in `src/App.jsx` when ready.
- Replace `Link coming soon` labels with public project URLs when available.
